# Logo

A solid root, connector lines, and empty nodes, because you render the nodes.

| File | Use |
|---|---|
| `logo-light.svg`, `logo-dark.svg` | Mark and wordmark, for light and dark backgrounds. The wordmark is outlined, so it needs no font. |
| `mark-light.svg`, `mark-dark.svg` | The mark alone (avatars, small spaces). |
| `favicon.svg` | The 16 px mark with two nodes; follows the browser's light or dark mode. |
| `social-preview.png` | GitHub's social preview, 1280 × 640 (repository settings → Social preview). |

Colours: ink `#15181C`, treeline green `#2E8B57`, paper `#FAFAF7`; on dark: night `#0E1311`, mist `#EEF2EE`, sprout
`#6ED6A0`. Wordmark: Space Grotesk SemiBold (SIL Open Font License), lowercase, −2.5% tracking.
